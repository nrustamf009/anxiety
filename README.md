# Тихие воды

Приложение, которое помогает справляться с тревогой через Писание, короткие практики и молитву. Работает без аккаунта и офлайн, рядом всегда кнопка срочной помощи.

> «…водит меня к водам тихим» — Пс 22:2

| Папка | Что внутри |
|---|---|
| [`reports/`](reports/) | Итоговый отчёт первого исследования: карта «симптом → стих», наука, конкуренты, право, план продукта |
| [`research_notes/`](research_notes/) | Исходные заметки исследования |
| [`mobile/`](mobile/) | Приложение (Expo / React Native) и редактируемый контент |
| [`docs/TECH.md`](docs/TECH.md) | Выбор технологий, дизайн-система, меры безопасности, что осталось до релиза |
| [`docs/ТЗ глубокое исследование 2.md`](<docs/ТЗ глубокое исследование 2.md>) | Готовое ТЗ для второго глубокого исследования (первоисточники, новые стихи) |

Это не медицинское изделие и не замена врачу или психологу.
