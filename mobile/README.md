# Тихие воды — мобильное приложение

Писание и молитва для тревожных минут. Expo (React Native) + TypeScript, офлайн, без аккаунта.

## Запуск

```bash
npm install
```

```bash
npm run content
```

```bash
npm start
```

`npm run content` скачивает тексты Библии (Синодальный, BSB, KJV) в `.cache/`, проверяет карточки и ссылки в обеих нумерациях и пишет `src/content/generated/`. Его нужно запускать после каждой правки в `content/`.

Другие команды:

```bash
npm run typecheck
```

```bash
npm run export:web
```

## Как добавить карточку

1. Скопируйте любой файл из `content/cards/` и поменяйте `id`.
2. Укажите ссылки в обеих нумерациях: `"syn"` (Синодальная) и `"eng"` (английская/еврейская). Пример: `"book": "Ps", "syn": "45:2-4", "eng": "46:1-3"`.
3. Запустите `npm run content`. Скрипт упадёт, если стих не найден, поле пропущено или встретилась запрещённая формулировка.

Подробнее о решениях и дизайне — в [`../docs/TECH.md`](../docs/TECH.md).
