# «Тихие воды»: технические решения

## Выбор стека

| Решение | Что выбрано | Почему |
|---|---|---|
| Платформа | **Expo (React Native) SDK 58 + TypeScript** | Один код для iOS, Android и веба. Android-сборка (APK/AAB) подходит и для Google Play, и для RuStore. Облачная сборка через EAS работает без Mac. |
| Навигация | **Expo Router** (`mobile/src/app/`) | Маршруты задаются файлами, есть deep links (`stillwaters://card/panic`). |
| Хранение | **Local-first:** AsyncStorage только для настроек | Без аккаунта и сервера: личное (молитвы, состояние) остаётся на телефоне человека. |
| Аналитика и реклама | **Нет** | Никакой слежки за тем, что человек читает в тревожную минуту. |
| ИИ | **Нет в MVP** | Чат-бот может выдумать «стих» или дать вредный совет. Возможный ИИ — только поиск по проверенной библиотеке карточек. |
| Контент | **JSON-карточки в `mobile/content/`**, собираются скриптом | Редакторы правят JSON, скрипт проверяет схему и ссылки, приложение работает офлайн. |
| Тексты Библии | **Синодальный (1876), BSB, KJV**, все в общественном достоянии | Берутся из [scrollmapper/bible_databases](https://github.com/scrollmapper/bible_databases) (MIT). В сборку попадают только нужные стихи. |
| Шрифты | **PT Serif** (Писание, заголовки) + **Manrope** (интерфейс) | Обе гарнитуры с полноценной кириллицей и лицензией OFL. PT Serif создан ParaType для русского языка. |
| Анимация | Встроенный `Animated` RN | Без лишних нативных зависимостей. Учитывается системная настройка «уменьшить движение». |

## Дизайн-система

Образ взят из Пс 22:2: «водит меня к водам тихим». Отсюда тишина, вода и свет на горизонте.

- **Светлая тема «Рассвет»:** пергамент `#F5F0E6`, глубокая вода `#2F5D6E`, свеча `#B08442`, шалфей `#6F8F7E`, терракота `#A8604F` для плача и кризиса.
- **Тёмная тема «Ночное озеро»:** для ночной тревоги и бессонницы. Включается автоматически по системной теме.
- **Подпись-иллюстрация:** горизонт над тихой водой со светом и отражением (SVG, `WaterHorizon.tsx`).
- **Дыхательный ритм:** круги на воде, 4 с вдох и 6 с выдох (около 6 дыханий в минуту, Bernardi et al., BMJ 2001).
- **Писание** набрано крупным PT Serif с золотой вертикальной чертой. Ссылка даётся в обеих нумерациях: «Пс 45:2–4 · Ps 46:1–3».
- Кнопка **«Срочная помощь»** видна на каждом экране.

## Структура

```
mobile/
  content/              ← редактируемый контент (источник правды)
    cards/*.json        ← 15 карточек «симптом → слово → толкование → практика → молитва → специалист»
    flows.json          ← вступление, SOS, сценарий плача
    crisis.json         ← экран срочной помощи (без привязки к стране) + кризисные слова
    books.json          ← названия книг RU/EN
  scripts/build-content.mjs  ← проверка схемы, сверка ссылок в обеих нумерациях, сборка
  src/
    app/                ← экраны (Expo Router)
      index.tsx         ← главная: SOS, навигатор состояний, плач
      welcome.tsx       ← вступление «Тревожиться — не грех»
      card/[id].tsx     ← карточка состояния (6 шагов)
      sos.tsx           ← «Мне тревожно сейчас»: дыхательная молитва
      lament.tsx        ← плач в 4 шага по Пс 12 (Ps 13) + «сегодня не могу довериться»
      crisis.tsx        ← срочная помощь: простые шаги + международный каталог линий помощи
      settings.tsx      ← перевод, традиция, о приложении
    components/         ← Icon (свои SVG), WaterHorizon, BreathPacer, Verse, ui
    content/            ← типизированный доступ + generated/ (результат сборки)
    lib/                ← settings (local-first), safety (кризисные слова, защита от «машины успокоения»)
    theme/              ← палитры, шрифты, отступы
```

## Встроенные меры безопасности

1. **Детектор кризисных слов.** Свободный текст в «Плаче» проверяется локально. При совпадении появляется карточка с переходом к живой помощи.
2. **Защита от «машины успокоения».** Это касается карточек, где возможен навязчивый поиск заверений (вина, здоровье). Если их открывают 4 раза за час, появляется мягкое объяснение и направление к специалисту по ЭПР (ERP). Счётчик хранится только в памяти.
3. **Проверка формулировок в сборке.** Скрипт не пропускает «лечит тревогу», «гарантирует», «клинически доказано» — приложение не обещает того, чего не может.
4. **Кризисный экран без стихов.** Там, где человеку нужен человек, нет ничего, что можно прочесть как «молись сильнее».
5. **Каждая карточка помечена как черновик**, пока её не одобрили богослов и клиницист (`review.status`).
